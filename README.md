📊 High-Level Infrastructure Discovery Questions (GCP Data Platform RFP)

Category	Question
Data Size	What is the total volume of data you currently manage (in TB or PB)?
	What is your expected data growth rate over the next 1–3 years?
Number of Sources	How many data-producing applications or systems are in scope?
	What types of systems are these? (e.g., ERP, CRM, logs, IoT, APIs)
Data Frequency	How frequently does data need to be ingested? (Real-time, hourly, daily?)
Users & Teams	How many users or teams will be accessing the platform?
	What types of users are expected? (e.g., analysts, engineers, data scientists)
Cloud Usage	Are you currently using GCP or planning a new setup?
	If on GCP, what services are already in use (e.g., BigQuery, GKE)?
Availability	What level of system uptime or availability do you require (e.g., 99.9%)?
Security	Are there any security or compliance standards that must be followed? (e.g., GDPR, HIPAA)
Performance	Do you anticipate peak loads or seasonal spikes in data volume or processing?
Integration	Are there existing tools or platforms that must integrate with the data platform?
Timeline & Budget	What is your expected timeline for implementation?
	Is there an estimated budget range for this initiative?
